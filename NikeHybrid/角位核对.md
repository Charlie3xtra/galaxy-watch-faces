# Nike 混合角位核对

参考 watchOS 24S132 的 NTKOlympusFaceBundle、NanoTimeKit、ComplicationDisplay 和 WeatherComplications。以下区分了固件中能定位到的模板和 Galaxy Watch 上实际提供的显示方式。

| 项目 | 可核对的固件证据 | Galaxy Watch 1.3 |
| --- | --- | --- |
| 音乐 | NTKMusicTimelineEntry.signatureCorner 传入摘要文字和图片。NTKRichComplicationCornerTextImageView 使用角位文字父类，CDRichComplicationCornerView 有按中心角排列弧形标签的方法。图集提供 rich-corner_music。 | 本地化音乐标签沿内侧圆弧排字，外侧使用角位音符。内置快捷方式显示静态标签。歌曲摘要取决于媒体数据源。 |
| 电量 | NTKBatteryTimelineEntryModel._signatureCornerTemplate 用电量比例构造带颜色的仪表，并把带百分号的文字传给 outerTextProvider。 | 当前表电量驱动短弧，外沿显示百分比。低电量配色阈值为移植取值。 |
| 心率 | NTKHeartRateTimelineEntryModel._newSignatureCornerTemplate 设置带 tint 的图像和 metadata。图集提供 RichCornerHeartrate。 | 专用心形加 Wear OS 提供的心率数值。数值沿弧线显示是三星版的布局选择。无读数显示横线。 |
| 天气 | WeatherComplications 含 GaugeText、GaugeImage、SegmentedGaugeImage、StackText 等角位模板。NanoWeatherComplications 图集提供天气无数据图。 | 天气状况显示温度和随状态切换的自绘图标；温度显示当日高低温区间内的当前位置；紫外线显示指数和仪表。数据取自系统天气。 |
| 电话、训练、信息 | Apple 官方预览展示三种独立轮廓。 | 使用预览提取的图案，点击行为由手表上的应用决定。 |
| 闹钟、日期 | NanoTimeKit 含闹钟圆形资源。 | 闹钟为图标快捷方式；日期显示星期和日号。 |
| 计时器 | 24S132 的 NTKTimerBundleTimelineEntry._newSignatureCornerGaugeImageTemplate 同时传入仪表、首尾文字和图标。文字和仪表都按计时状态取值，时间提供器区分暂停。 | 新增长文本槽。内置计时外观使用 NanoTimeKit 的 timercolor 图案。实测启动五分钟计时后，系统浮层倒数，角位仍显示 Timer。当前未复现 Apple 的倒计时进度弧、多计时和暂停样式。 |
| 秒表 | NTKStopwatchTimelineEntry._graphicCornerTemplate 配置橙色系统符号和计时文字提供器。 | 三星秒表提供运行和暂停读数，角位绘制橙色秒表符号。符号为重绘。真机运行时显示 00:06，暂停后角位显示 01:35，应用内显示 01:35.12。 |
| 世界时钟 | NTKWorldClockTimelineEntryModel._graphicCornerTemplate 的两种组合分别使用应用名和地球图标、带时差的时间和城市缩写。 | 可选三星城市数据源，沿两条弧分别排列正文和标题。手表未选择城市时，已验证显示 World Clock。城市、时差和更新行为取决于数据源，未验证选城后的显示。 |
| 天文 | NTKAstronomyRichComplicationCornerView._updateInnerLabel 读取模板元数据，用日期和位置构建事件日期文字。NanoUniverse 另有 VictoryNTKMoon 的 112 幅连续月相遮罩。 | 选取 28 幅遮罩，由 Wear OS 月龄切换，并显示系统月相名称。已在表上看到月面。暂未实现 Apple 基于地点的事件时间、地球及太阳系视图。 |
| 海拔 | AltitudeRichCornerDialView 的 _newTopView 和 _newBottomView 分别以图片创建视图。AltitudeComplicationDataSource 区分正常、无数据、隐私和常亮模板。 | 使用固件角位高度表图，缺少高度读数显示横线，点按打开指南针。这台表的指南针只注册了 Barometer 气压组件。另装海拔提供器后可以从系统组件页选择，其返回值走通用数据排版，尚未实测。 |

在支持 Wear OS 表盘预设的选择器中，“计时器 · 世界时钟”预设将左上、右上、左下分别绑定三星计时器、秒表和世界时钟，右下使用月相。也可以在三星表盘编辑器中给任意角选择数据源。只更换角位图案会改变外观和快捷入口；实时计时和城市数据由系统组件提供。

四个 80 单位触摸区的中心位于 480 画布的 (101,101)、(379,101)、(101,379)、(379,379)。数字图层等比缩小约 7%，避免斜角组件压到时间。全屏数字布局用 24 个小时和 60 个分钟的实心、描边字形检查，触摸圆到笔画的最小间隙约 6.5 个设计单位。
